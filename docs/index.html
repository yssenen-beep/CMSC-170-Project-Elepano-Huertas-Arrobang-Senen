Like the desktop UI, Backtracking uses the requested gap as a target; A* and GA always minimize gaps. Common fitness still penalizes total idle time, so use target error to compare how closely the schedules match a requested gap.

All outputs use the same fitness evaluator. Search spaces and stopping rules differ, so these results compare the current implementations on the selected test scenarios.
